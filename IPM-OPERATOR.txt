Proof Before Pay: IPM operator guide

Application code: MIT. The separately licensed AI Hub Community EAP build154 image
and vendor SDK are prerequisites; this repository and its IPM package contain neither.
Tested platform: x86-64 Linux, build154, Python3.12.3 and IPM0.10.10.
The manifest's version floors do not establish support for other IRIS builds.

ISOLATION
Use a dedicated private instance. A second namespace is not enough: Setup installs
fixed instance-wide /pbp/api and /pbp/ui web applications and reviewer resources.
Start with the plain vendor image and a functioning IPM installation, without PBP
classes, Python packages or a prebuilt PBP application image masking missing resources.
When provisioning a new Docker durable volume, give its empty root to the vendor's
UID/GID51773 before starting IRIS. Do not chown an existing application volume.
Do not weaken permissions on /usr/irissys/lib; assets use a per-app manager directory.

INSTALL
1. Keep PBP_LLM_MODE=recorded and all provider keys absent. No model inference is
   needed for this installation or its recorded integration checks.
2. Obtain IPM from its official release and verify the release digest. One earlier
   bare-image0.10.10 bootstrap failed with NAMESPACE/PushNS before app loading.
   A later fresh-volume trial passed after waiting at least45seconds, checking
   vendor logons were enabled and USER existed from %SYS, then loading in USER.
   That historical run used process-local diagnostic tracing. On31October an
   agent follow-up (Codex-authored step, after a Claude-authored attempt that
   deviated from this guide by loading in %SYS) bootstrapped the identical
   installer in USER without tracing on a new plain-vendor volume under x64
   emulation on Apple Silicon, with2GiB RAM and0.75CPU. Native load and version
   statuses both passed. Claude reviewed and accepted the Codex supplements.
   This is not an independent bootstrap. The failed %SYS attempt was preserved;
   USER could not find %IPM.Main after that attempt. Bootstrap in the intended
   interoperability namespace, not %SYS expecting the USER API to be present.
   The cause of the earlier PushNS failure remains unproved. These are observed
   readiness checks, not a guarantee that waiting45seconds fixes every startup.
   On that same fresh volume, first PBP installation and48recorded workflow checks
   passed. The earlier package/uninstall/reinstall trial used initialized IPM.
   See docs/validation/native-IPM-bootstrap.json for the separate evidence scopes.
3. Public registry installation is available as of03November. In a dedicated
   interoperability instance with IPM installed, enable the official public
   repository if the lab was previously configured offline:

   set sc=##class(%IPM.Main).Shell("repo -r -n public-community -url https://pm.community.intersystems.com/ -enable -prereleases 1 -publish 0")
   set sc=##class(%IPM.Main).Shell("install proof-before-pay -v")
   write $system.Status.GetErrorText(sc),!

   The public prerelease tested on03November is0.1.0-beta.2. Native install status,
   47 resources, seven Embedded Python imports and stopped Production were checked
   in an isolated copy of an initialized IPM lab; no old instance was changed.
   See docs/validation/IPM-public-beta2-20261103.json.
   The beta.3 candidate adds explicit source restoration/rebinding, Gemini3.6
   support and the dedicated demo no-repair guard. Public beta.3 registry
   installation has not yet been qualified; do not infer it from the beta.2 proof.

   Alternatively, clone the source and use an interoperability-enabled namespace:

   set sc=##class(%IPM.Main).Shell("load /absolute/path/to/proof-before-pay -v")
   write $system.Status.GetErrorText(sc),!

   Require a successful %Status and the actual loaded resources, not just the
   operating system's terminal exit code.
4. IPM processes requirements.txt at the module root. It is byte-identical to the
   hash-pinned requirements.lock. The native offline test supplied the verified
   rfc8785-0.1.4 wheel through PIP_NO_INDEX=1 and PIP_FIND_LINKS=/path/to/wheels.
   It did not bypass Python dependency installation. The separate03November
   public-registry installation fetched rfc8785 online and imported it natively.
5. Configure calls pbp.Setup.Install(managerDirectory_"proof-before-pay",0).
   The0.1.0-beta.3 source declares47class resources and7Python packages.
   Verify that Production has not started, every declared class exists,
   and all seven packages resolve from managerDirectory_"python", and policy,
   replay fixtures and UI files exist in the per-app manager directory.
   The optional legacy pbp_seal/Solana library is not part of the native IPM module.
6. After checking recorded mode and the absence of provider credentials, start
   pbp.Production explicitly and run fresh synthetic cases. Verify authenticated
   review, one intact sandbox receipt, missing-evidence refusals and tamper detection.
   In this fresh disposable acceptance lab, the following USER terminal commands
   run the repository's recorded workflow smoke with the IPM-installed assets:

      set s=##class(%SYS.Python).Import("sys")
      do s.path.insert(0,"/absolute/path/to/proof-before-pay/tests/iris")
      set m=##class(%SYS.Python).Import("production_smoke")
      set result=m.run($system.Util.ManagerDirectory()_"proof-before-pay")
      write "E2E=",result,!

   The helper explicitly starts Production through Setup.Install(root,1).
   Require JSON ok:true and all48 checks, including review_note_sealed and
   rejection_note_sealed. It creates uniquely named synthetic cases and one
   test-ledger effect; it is an automated installer-session review, not a browser
   review or Rafael's approval. Do not replay this smoke on an instance whose
   unrelated application state you need to preserve. The separate private HTTP
   reviewer recipe is docs/REVIEWER-SETUP.md; no HTTP port is enabled by IPM itself.

PACKAGE / UNINSTALL / LOCAL REINSTALL
The native acceptance generated a source-only package with:

   set sc=##class(%IPM.Main).Shell("package -only -path /tmp/pbp-package proof-before-pay -v")

The resulting file is /tmp/pbp-package.tgz, not a file inside a directory of that name.
Inspect its contents before distributing it. No vendor image, private files,
credentials, compiled database files or optional Solana SDK are included.

Before uninstalling, stop pbp.Production and keep a separate backup of application
data. Use a disposable acceptance instance to test the default, non-purge uninstall:

   set sc=##class(%IPM.Main).Shell("uninstall proof-before-pay -v")

Each FileCopy has its own package or asset target; never use the shared manager
Python root as an uninstall target. Native tests checked unrelated file sentinels
and reloaded the generated archive with the original intact single-effect receipt.
Do not assume that uninstall reverses custom Setup side effects: reviewer resources,
Workflow definitions, web application settings and manual audit globals are not
declared as standalone uninstall resources. Plan their decommissioning explicitly
and preserve the evidence. Do not use -purge against application data you need.

The0.1.0-beta.2 candidate adds optional native LIVE actors, local policy RAG
and the devnet-only SolanaMemo adapter. The public0.1.0-beta.1 installation
evidence remains historical and does not prove installation of those additions.
A normal install does not stage a LIVE profile, index a KB, enable an adapter,
create a provider/wallet key or make a model/blockchain request. Optional solders
dependencies are separate and required only when explicitly configuring devnet.

Local archive loading is separate from publication:

   set sc=##class(%IPM.Main).Shell("load /tmp/pbp-package.tgz -v")
